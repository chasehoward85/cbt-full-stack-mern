# About this App
This app was created by following Shawn Wassell's full stack course on CBTNuggets. It is a note sharing app that utilizes Socket.io, Express, Google Firebase, MongoDB and Node. Some of it was modernized to 2026 versions, but the majority of it came from him

## Reasoning
I took this course to get a better understanding of React and JavaScript. I will be using the content from it in my own personal projects in the future

## How it Works
This app works by utilizing a few different frameworks
- Google Firebase for user authentication
- Express for POST requests
- Socket.io for sockets
- Node for package management
- MongoDB for the database
